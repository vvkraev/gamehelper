# Высокий порог входа как защита ниши

**Статус:** new  
**Источник:** разговор 2026-06-28

## Гипотеза

Чем сложнее крафт — тем дольше он остаётся прибыльным.
Массовые игроки не войдут даже после видео, если нужны редкие материалы + знание механики + автоматизация.

## Что создаёт высокий порог

- **Редкий материал** (нужен орб за 5+ div) → мало людей имеет запас
- **Сложный пайплайн** (10+ шагов, специфическая последовательность) → ошибки дорого стоят
- **Нужна автоматизация** → ручной крафт нерентабелен по времени
- **Нужна база** (fractured или специфический ilvl) → доступна не всем

## Следствие для нашего проекта

Наше приложение снижает порог **для нас**, но не для рынка.
Это постоянное конкурентное преимущество: крафт, который требует автоматизации, для нас — рутина, для других — недоступен.

## Крафты с высоким барьером (проверить в следующей лиге)

- Overflow-крафт (3 суффикса при лимите 2 → хаос только по префиксам)
- Desecrate + Liquid Currency пайплайн
- Aug+Annul на Magic с несколькими ценными модами
