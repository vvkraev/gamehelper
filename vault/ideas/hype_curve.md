# Кривая хайпа крафта

**Статус:** validated  
**Источник:** личное наблюдение

## Гипотеза

Любой новый крафт проходит предсказуемый цикл:

```
День 0-1:  Открытие → маржа ~100%, предложение = 0
День 2-4:  Распространение в Discord/стримах → маржа падает
День 5-7:  Выходят объясняющие видео → массовый вход
День 7+:   Предложение >> спрос → маржа отрицательная
```

## Следствия

- Окно максимальной прибыли: **4-7 дней с момента открытия**
- После видео на ютубе = поздно входить
- Чем сложнее крафт (порог входа) — тем дольше окно

## Что нужно

Входить **до** видео, то есть находить сигнал раньше массы.
Источники раннего сигнала → [[patchnotes_signal]], [[price_anomaly_detection]]

## Открытые вопросы

- Зависит ли длина окна от сложности крафта?
- Есть ли паттерн у того, кто первым «открывает» крафт (один и тот же круг людей)?
