## Важное открытие: доминирующий паттерн — не тот, что мы моделировали

Из 14 однокрит-предметов **10** имеют одинаковую структуру:

```
{ Frac CS } 10% Critical Spell Damage Bonus
{ Expl }    7% Critical Hit Chance          ← CC
{ Expl }    7% Critical Hit Chance for Spells ← CCS
{ Des  }    1% max Mana
{ Craft}    Upgrades Radius to Very Large
```

Это **один крит-бонус к урону (CS) + два крит-шанса (CC + CCS)** — другой продукт, не тот что мы моделировали.

Наша модель целилась в: **CD + CS** + один из {CC, CCS, ManaKill, ...}  
Рынок предлагает ещё: **CS only** + CC + CCS

## Как крафтится CS + CC + CCS?

Вероятно не через хаос-крафт, а через другой маршрут:

**Вариант A:** Frac CS база → chaos до CC (p≈19% за попытку на 2 слота) → omen+exalt до CCS  
**Вариант B:** Frac CS база → exalt CC → exalt CCS (два экзальта в суффиксы через оменов)

Вариант A дешевле: E[хаос] ≈ 5 orbs (≈0.7 div), затем E[экзальт до CCS] при p≈4.9% = ~20 попыток.

> ⚠ Это отдельный крафт, требует отдельного анализа. Здесь только рыночные цены.

## Чего по-прежнему нет

**Нет данных** по однокрит-предметам нашего целевого типа:
- Frac CD + CC (без CS) — **0 в снэпшотах**
- Frac CD + CCS (без CS) — **0 в снэпшотах**
- Frac CD + ManaKill (без CS) — **0 в снэпшотах**
- Frac CS + CC (без CCS) — **0 в снэпшотах** (есть только с обоими CC+CCS)
- Любой другой из 7 аффиксов как единственный суффикс + один крит-бонус — **0**

Вывод: **рынок однокрит предметов с одним суффиксом (Frac + один цель) отсутствует** в текущих снэпшотах. Либо таких предметов очень мало, либо продавцы их не листируют по заметным ценам.
