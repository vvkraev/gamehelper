# TLS Sapphire: правила шага 1 — что принимать, что перероллить

*2026-07-05. Математически выведено из Markov-цепей + рыночных цен снэпшотов.*

---

## Главное правило

**Принять аффикс X на шаге 1, если** `price(CD+CS+X) > 360d`

360d — средняя выручка стандартного двукрита. Всё ниже 360d — выгоднее перероллить хаосом.

---

## Таблица решений — шаг 1

| Аффикс | Шаг 1? | price(CD+CS+X) | Шаг 3 (если взяли) | Причина |
| :--- | :---: | :---: | :--- | :--- |
| **CS** (крит бонус к заклинаниям) | ✅ БРАТЬ | — (стандарт) | любой из 7 (26.16%) | основной путь |
| **CCS** (крит шанс для заклинаний) | ✅ БРАТЬ | 499d | только CS (4.42%) | 499d > 360d |
| **MK** (Osmosis, мана при убийстве) | ✅ БРАТЬ | 698d | только CS (4.42%) | джекпот |
| **Mind** (урон из маны) | ✅ БРАТЬ | 577d | только CS (4.42%) | 577d > 360d |
| **CC** (крит шанс) | ❌ ПЕРЕРОЛЛИТЬ | 336d | — | 336d < 360d |
| CastSpeed (скорость каста) | ❌ ПЕРЕРОЛЛИТЬ | 190d | — | 190d < 360d |
| Notable (эффект нотаблей) | ❌ ПЕРЕРОЛЛИТЬ | 325d | — | 325d < 360d |
| SkillDuration | ❌ ПЕРЕРОЛЛИТЬ | ~180d | — | < 360d |

> **Почему CC не берём:** CD+CC+CS продаётся за 336d — это ниже среднего по двукриту (360d). Принять CC = согласиться на худший исход, чем продолжать крафтить.
>
> **Почему CCS берём:** CCS и CS имеют одинаковый вес в пуле (4.42%). Вероятность CS из экзальта (4.42%) выше, чем CS из хаоса при стандартном двукрите (1.69%). Принять CCS → доделать предмет через экзальт в CS → 499d.

---

## Правило шага 3 (экзальт)

| Что на предмете после шага 1 | Шаг 3 принимает | p₃ | E[выручка] |
| :--- | :--- | :---: | :---: |
| CS | CC, CCS, MK, CastSpeed, Notable, SkillDur, Mind | 26.16% | 360d |
| CCS | только CS | **4.42%** | 499d |
| MK | только CS | **4.42%** | 698d |
| Mind | только CS | **4.42%** | 577d |

В ветках CCS/MK/Mind — **принимаем ТОЛЬКО CS**. Если экзальт дал CC или CCS — аннулировать и повторить.

## Математический итог

| | Стандартный двукрит | Оптимальная стратегия |
| :--- | :---: | :---: |
| Принимаем на шаге 1 | CS | CS, CCS, MK, Mind |
| p₁ | 1.69% | **4.49%** (×2.66 быстрее) |
| E[себестоимость] | 179.7d | 191.2d |
| E[выручка] | 360d | **395.5d** |
| **E[маржа]** | **+180d** | **+206d (+14%)** |
| P(джекпот 698d) | 8.75% | **16.68%** |

> Себестоимость растёт (+11.5d), потому что ветки CCS/MK/Mind имеют дорогой экзальт (p₃=4.42% vs 26.16%). Но выручка растёт на 35.5d → чистый прирост +25.8d маржи.

## Откуда берётся прирост маржи

Доли завершённых предметов в оптимальной стратегии:

| Ветка | Доля | Выручка | Вклад |
| :--- | :---: | :---: | :---: |
| CS (стандарт) | ~85% | 360d | ~306d |
| CCS → CS | ~9.7% | 499d | ~48d |
| MK → CS | ~4.3% | 698d | ~30d |
| Mind → CS | ~1.0% | 577d | ~6d |
| **Итого** | | | **~390d** |

Джекпот 698d теперь производится двумя путями:
- CS на шаге 1 → MK на шаге 3 (2.29% успехов CS-ветки)
- MK на шаге 1 → CS на шаге 3 (100% успехов MK-ветки)
P(698d предмет) удваивается: с **8.75% → 16.68%**
