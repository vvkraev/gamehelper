## Стартовые условия шага 3

На предмете в момент экзальта:
- `{ Frac }` Critical Damage Bonus 10% (**of Potency**)
- `{ Expl }` Critical Spell Damage Bonus 10% (**of Unmaking**)
- `{ Expl }` +1 к максимуму суффиксов (от Ancient Potent Liquid Contempt)

Omen of Dextral Exaltation + Exalt добавляет **один суффикс** из пула TLS Sapphire,
исключая уже присутствующие (CD и CS исключены). Пул: **5 589** взвешенных наблюдений.

## E[стоимость крафта суффиксов] — аналитическая формула

Маркова-цепочка для шагов 1–3 с восстановлением через аннулмент:

```
E₃ = (1/p₃) × { C₃ + (1−p₃) × [recovery + (7/6p₁)C₁ + (4/3)C₂] }
E₁ = 2C₁/p₁ + 2C₂ + E₃
```

Параметры (текущие цены 2026-07-04):

| :--- | :--- |
| C₁ (Chaos Orb) | 1 chaos |

## Выводы

1. **Расширенный пул выгоднее**: маржа **+180 div** vs **+154 div** у исходного 2-аффиксного (+26 div).
   Экономия на крафте (−53 div себестоимости) перевешивает снижение средней выручки (−26 div).

2. **Главная статья затрат — база** (75 div из 180 div), не крафт суффиксов (74 div).

3. **«of Osmosis» (Mana on Kill) — самый дорогой** (698 div), дороже CritSpellChance (499 div).
   Редкий (2.29%), но вносит 61 div в E[выручку] — больше чем CritSpellChance (84 div только потому что он чуть более вероятен).

4. **«of Enchanting» (Cast Speed) — слабое звено**: самый частый из новых (5.99%), самый дешёвый (190 div).
   Тянет E[выручку] вниз, но ускоряет крафт. Без него:
   - p₃ = 22.17%, E[крафт] = 89 div, E[себестоимость] = 194 div
   - E[выручка] без CastSpeed = ~375 div → E[маржа] ≈ **+181 div**
   - Практически то же самое, что и с 7 аффиксами. Разница несущественна.

5. **«of Mind» (Mana before Life) теперь имеет данные**: 577 div (8 позиций в снэпшотах).
   Редкий (0.63%), но ценный — дороже CritChance.

6. **«of Lengthening» (Skill Effect Duration) — данных мало** (3 позиции, 160/180/788 div).
   Нельзя уверенно оценить цену. Медиана 180 div противоречит единственной продаже за 450 div.
