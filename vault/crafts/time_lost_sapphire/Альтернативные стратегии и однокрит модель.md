# Альтернативные стратегии крафта TLS — анализ

Отвечаем на три вопроса:
1. Можно ли поменять последовательность крафта?
2. Какие ещё комбинации аффиксов возможны?
3. Что будет, если убрать один из крит-бонусов?

---

## 1. Можно ли поменять последовательность?

Текущая последовательность: **хаос → CS, экзальт → один из 7 аффиксов**.

Альтернатива — поменять местами: **хаос → любой из 7, экзальт → CS**.

Итоговый предмет тот же (CD + CS + 3rd suffix), но эффективность резко падает:

| Стратегия | p1 (хаос) | p3 (экзальт) | E[крафт суфф.] | E[маржа] |
| :--- | :---: | :---: | :---: | :---: |
| **Текущая** (хаос→CS, экзальт→7) | 1.69% | 26.16% | **74 div** | **+180 div** |
| Поменять местами (хаос→7, экзальт→CS) | 10.03% | 4.42% | **214 div** | **+40 div** |

**Почему нельзя менять местами:** экзальт — дорогой шаг, его надо направлять в самый широкий пул (26.16%), а не в узкий (4.42%). Шаг 3 через аннулменты тянет назад к шагу 1 при каждом провале — и если p3 низкое (4.42%), это происходит часто.

**Вывод: текущая последовательность оптимальна. Менять не нужно.**

## 3. Что будет если убрать один из крит-бонусов?

### Стратегия 3А — чистый однокрит (без шагов 2-3)

Условие стопа на шаге 1: хаос выдал frac CD + **любой из 7 целевых суффиксов**.

- p1 = 10.03% (в 5.9× выше, чем у шага 1 текущей модели)
- E[хаос] = ~10 orbs ≈ **1.4 div**
- Шаги 2-3 **пропускаются** (нет нужды в +1 max suffix, нет экзальт-цикла)
- Итого: E[себестоимость] = 1.4 + 75 + 10 + 20 = **~107 div**

Из step 1 успехов **16.9% — это CS**, то есть двукрит-предмет (CD + CS). Их нужно обрабатывать по полному маршруту (продолжить шаги 2-3) или продавать как есть.

| Показатель | Двукрит (тек.) | Однокрит (стр. 3А) |
| :--- | :---: | :---: |
| E[себестоимость] | 180 div | **~107 div** |
| E[выручка] | 360 div | **~130 div** ⚠ мало данных |
| E[маржа] | +180 div | **+24 div** ⚠ |
| Предметов в час | × | ×**5.9** |
| Маржа / час | ~ | **неясно** (нужно больше цен) |

> ⚠ E[выручка] для однокрит-стратегии ненадёжна: всего 8 продаж, широкий разброс.

### Гибридная стратегия 3Б

Условие шага 1: **любой из 7** (включая CS).
- Если CS выпал (16.9% случаев) → предмет двукрит → **продолжить шаги 2-3** (полный маршрут)
- Если не CS (83.1%) → продать как однокрит (шаги 4-5 без 2-3)

E[маржа гибрид] ≈ **+63 div** (грубая оценка — доверять только при наличии цен на однокрит)

## Главный вывод

**NotableEffect («of Supremacy») — единственный аффикс, где однокрит-стратегия может быть интересна:**
- Двукрит продаётся за 325 div, однокрит за 239 div (потеря только 26%)
- Относительно частый в пуле (1.50%)
- При большом кол-ве крафтов потенциально интересен как «быстрая» позиция

**Для всех остальных аффиксов** потеря ~60% стоимости при отказе от второго крит-бонуса делает однокрит нерентабельным при текущих данных.

**Главная проблема:** данных о ценах однокрит-предметов слишком мало (1-4 продажи). Прежде чем принимать решение — нужно снять снэпшот рынка специально по однокрит-фрактурам TLS Sapphire.
