# Стратегия: Масс-крафт Vile Robe (ES)

Полный документ: `docs/VILE_ROBE_MASS_CRAFT.md`

## Цель

Fractured % inc ES T1 + flat ES T1 + Desecrate мод + 3 сокета → 1000+ ES.

## Пайплайн

```
1. Aug + Annul цикл → синяя база [ES prefix T1 + resist suffix T2]
2. Regal или Essence → Rare [3 мода]
3. Добавить Desecrate → 4 мода (нужно для Fracturing Orb)
4. Fracturing Orb → зафрактурить ES T1 (P = 1/3 с Desecrate)
5. Докрафт до 6 модов
6. Divine → улучшить роллы (особенно фрактуру → 1000 ES порог)
7. Руны (3× Iron или Masterwork) → финальный ES
```

## Иерархия ценности синих баз

1. `[Spirit T1] + [resist T2]` — джекпот, продавать/спецсценарий
2. `[% inc ES T1] + [resist T2]` — основной продукт
3. `[flat ES T1] + [resist T2]` — второй сорт
4. `[combined ES T1] + [resist T2]` — третий сорт

## Ключевые механики

**Desecrate + Fracturing Orb:**
3 мода Rare → добавить 1 Desecrate → 4 мода.
Fracturing Orb не может фрактурить Desecrate → P(попасть в ES T1) = **1/3** вместо 1/4.

**Порог 1000 ES:**
Покупатели фильтруют ≥ 1000. Предмет ниже — теряет половину аудитории.

**Regal vs Essence:**
- Regal: высокая дисперсия (может дать Spirit или мусор)
- Essence (Greater of Thawing/Smothering/Electricity): гарантированный T4 резист, предсказуемый старт
- **Важно**: Essence блокируется если на предмете уже есть мод того же резист-семейства
- После любого пути: 3-модный Rare неликвиден → **обязательно довести до 6 модов**

| 1000+ ES базовый | 100–179 div |
