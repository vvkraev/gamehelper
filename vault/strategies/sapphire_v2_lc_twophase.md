# Пайплайн v2: двухфазный LC (без Desecrate)

**Статус: ТЕОРЕТИЧЕСКИЙ** — не верифицирован на практике.  
Ключевое допущение не подтверждено (см. ниже).

## Идея

Вместо Desecrate для CHS — использовать LC дважды:
- Фаза 1: Chaos → первый суффикс (CD или CSD)
- Фаза 2: LC 50/50 → защитить первый суффикс (если попали — продолжаем, нет → хаос заново)
- Фаза 3: Chaos → второй суффикс (первый защищён overflow или crafted)

## Математика (рассчитано 2026-06-27)

Цены: хаос = 0.1039d, LC = 2.15d

| Параметр | Значение |
|---|---|
| P(нужный суффикс за хаос) | ~1/35 ≈ 2.86% |
| E(хаосов) Фаза 1 | ~10.5 = 1.09d |
| Рекурсивная Фаза 2 (LC + повторы) | ~6.48d |
| E Фаза 3 (с учётом +1S риска) | ~5.9d |
| **Итого суффиксный этап** | **~12.4d** |

Для сравнения — v1 (Desecrate): ~22d только за CHS.

## Ключевое НЕРАСКРЫТОЕ допущение

> **Выживает ли первый суффикс при хаосе в Фазе 3?**

Это зависит от того, остаётся ли crafted "+1 Suffix" prefix на предмете в момент Фазы 3.
- Если да → overflow → хаос не трогает суффиксы → **стратегия работает**
- Если нет → хаос перекатывает все суффиксы → **стратегия не работает**

**Проверить в игре перед использованием.**

## Выигрыш если работает

v2 дешевле v1 на суффиксном этапе: ~12.4d vs ~22d.
Экономия ~10d на базу → при 131d базовой себестоимости → ~121d.
