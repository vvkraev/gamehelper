# Пайплайн v1: CS+CD+CHS через Desecrate

Верифицирован на практике (батч 2026-06-26, 4 базы).

## Цель

```
CS 12% (frac) + CD 12% + CHS 8% (desecrate) + VL radius + T1 prefix
```
CS/CD/CHS прокачиваются качеством: Refined Sibilant Catalyst ×4 = +20%.

## Шаги

```
1. Купить базу ilvl 80+ с CS=10% на суффиксе (или диваинить до CS=10)
2. Добавить Desecrated PREFIX (Preserved Cranium)
3. Fracturing Orb → зафрактурить CS suffix (P = 1/3, E = 3 попытки)
4. Orb of Annulment ×2 → оставить только CS(frac)
5. Chaos Orb → искать CD suffix (E ≈ 35 хаосов)
6. Exalt ×2 → заполнить до 2P+2S
7. Potent Liquid Contempt → попасть в PREFIX (50/50, E = 2 попытки)
   — промах: Annulment ×2 → вернуться к шагу 5
8. Desecrate: Preserved Cranium + Abyssal Echo
   → искать CHS suffix (P ≈ 17.6% за цикл, E ≈ 3 цикла → ~22d)
9. Divine (опционально) → улучшить CSD roll
10. Omen of Sinistral Annulment → убрать crafted PREFIX (50/50, E = 2 попытки)
    → после: 3 суффикса при лимите 2 = OVERFLOW
11. Chaos (overflow) → искать COUNT≥2 T1 prefixes (~129 хаосов avg)
12. Delirium Oil → VL radius, убирает 1 random PREFIX (50/50)
13. Refined Sibilant Catalyst ×4 → качество +20%
```
