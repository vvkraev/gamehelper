# Механика Освящения (Sanctification)

> **Источник:** Omen of Sanctification + Divine Orb  
> **Применяется к:** Rare предметам  
> **Нельзя применять к:** corrupted предметам

---

## Как работает

1. **Omen of Sanctification** помещается в инвентарь и активируется (Right click).
2. Следующий **Divine Orb**, применённый к Rare предмету, **Освящает** его.
3. Каждый модификатор получает **свой независимый случайный множитель 78–122%** — значения могут расти или падать по-разному на одном предмете. Тиры не меняются.
4. Предмет становится **Sanctified** — большинство методов крафта и изменений к нему **больше не применимы**.

> Ключевое отличие от corruption: результат предсказуем по диапазону (78–122%) и применяется к уже известным модам — нет случайного добавления/удаления/трансформации.

## Отличие от корраптирования

| | Corruption (Vaal Orb) | Sanctification |
|---|---|---|
| Доступность | Все Rare/Magic/Normal | Только Rare, некорраптированные |
| Изменение модов | Random outcome (4 варианта) | Масштабирование каждого мода на 78–122% |
| Предсказуемость | Низкая | Средняя (диапазон и моды известны заранее) |
| Стоимость | Vaal Orb | Omen of Sanctification + Divine Orb |
| Лок крафта | Полный | Большинство методов (не все) |

## Крафтовые моды на освящённых предметах

Освящённые вещи часто имеют **2–3 крафтовых мода** с тиром **S0 / P0** — это нестандартный «нулевой» тир, получаемый через специфическую крафтовую механику (не через обычный Crafting Bench). Характерные семейства:

| Мод | Тип | Стат |
|---|---|---|
| `of the Essence S0` | Суффикс | +3–4 to Level of all Spell Skills |
| `of the Stars S0` | Суффикс | % increased Cast Speed + Gain X% Elemental as Extra Cold |
| `Verisium P0` | Префикс | +X to maximum Mana |

Наличие S0/P0 в `mods_crafted` — **надёжный признак освящённого предмета** в существующих данных (пока GGG API флаг `sanctified` не подтверждён на raw-захвате).

## Детектирование в коде

```csharp
// TradeSnapshotDiffService.LoadSnapshot():
// 1. Проверяет API-поле item["sanctified"] (если добавят)
// 2. Fallback: ищет S0/P0 тир в mods_crafted
Sanctified = node["sanctified"]?.GetValue<bool>()
    ?? modsCrafted.Any(m => Regex.IsMatch(m, @"\s[SP]0[\s—]"));
```
