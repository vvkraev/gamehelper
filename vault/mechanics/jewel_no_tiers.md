# Jewel: нет тиров аффиксов

**Статус:** verified  
**Источник:** 2026-06-28

## Механика

У **всех Jewel** в PoE2 каждое семейство аффиксов имеет только **один тир — T1**.

Следствия:
- ilvl jewel не влияет на доступность аффиксов
- Jewel любого ilvl даёт идентичный пул модов
- При покупке базы для крафта ilvl не является критерием

## Отличие от обычных предметов

У обычных предметов (броня, оружие, аксессуары) аффиксы имеют несколько тиров,
и ilvl определяет доступность тиров. Для jewel это правило не действует.

## Применение

- При оценке базы jewel для крафта — смотреть только на implicit, fractured мод, цену. ilvl игнорировать.
- При расчёте Desecrate пула — ilvl не влияет на доступные суффиксы.
