# Флор таблеток — механика и данные

## Что такое флор

Минимальная рыночная цена таблетки данного **типа** (например «Ritual Tablet»),
определяемая механикой рефорджа: 3 одинаковые таблички → 1 случайная новая.
Ниже этой цены продавать невыгодно — дешевле отдать на рефордж.

Флор — **per tablet type**, не per комбинация модов.

## Как считать

Снэпшот без условий по модам, только фильтр по типу таблетки → p10 цен листингов.
Снэпшот называется `rit_floor` (или аналогично для других типов).

**Формула:**
```
floor(тип) = p10(listing_prices[тип]) в divine
```

Не минимум (выбросы), не среднее (шумное) — 10й перцентиль.

## Применение в reprice.py

`CHAOS_MIN = 3` (~0.42d) — немного выше флора 0.35d, не снижаем ниже рефордж-пола.

Шаг снижения в chaos адаптивный (~10% от текущей цены):
```python
def chaos_step(price): return max(1, round(price * 0.10))
```

## Для белых (Normal) таблеток

Флор = max(рефордж-флор, EV шансинга):
```
floor_white(тип) = max(floor_reforge(тип), EV_chance(тип))
EV_chance(тип)   = цена_Orb_of_Ancient / P(получить уникальную)
```

Если уникальные таблетки типа дорогие → шансинг поднимает флор выше рефорджного.
